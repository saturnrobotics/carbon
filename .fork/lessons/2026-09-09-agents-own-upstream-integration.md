# Agents own upstream integration

**Context:** An operator asked the coding agent to complete an upstream sync.

**Problem:** A manual worktree and generator checklist transferred routine
integration work back to the operator and stopped at locally fixable prerequisites.

**Rule:** Own discovery or resumption, source reconciliation, isolated tool setup,
disposable schema regeneration, verification, and normal commits. Carry out
candidate publication, exact-SHA CI, and verified promotion when covered by the
sync request. Preserve existing edits and resolve recoverable failures without
asking the operator to run engineering commands. Ask only for unavailable access
or an unresolved decision; keep deployment separate and never bypass protections.
Use persistent worktrees for new syncs and safely resume existing temporary ones.

**Applies to:** Upstream synchronization, generated-conflict repair, fork agent
policy, and operator workflow documentation.
